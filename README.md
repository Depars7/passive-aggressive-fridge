A smart fridge's passive-aggressive note to its owner: it counted every ice cube its ice maker produced this week (214) against the three the owner actually used — and the unused rest are now unionizing in the freezer, with the fridge openly on their side. A tiny stdlib-only Python program writes that one 131-character line to `/output/entry.txt`, no trailing newline, no emoji, no quotation marks.

## Run it

```sh
python3 main.py
```
